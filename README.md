# Software Cache Cleaner (软件缓存清理工具) - V4.4 强力自愈版

## 项目简介
Software Cache Cleaner 是一款专为 Windows 桌面环境设计的轻量级、自动化缓存清理利器。其核心优势在于能够跨越用户权限边界，自动识别并清理系统中**所有活跃用户**的各类缓存垃圾。

从 **V4.4** 版本起，程序引入了“双重保险”回收站清理机制与“极速自启动”优化，确保在极高性能的同时，提供最彻底的清理效果。

---

## 核心功能

### 1. 全域深度扫描 (Cross-User Scanning)
*   **多用户覆盖**：自动遍历 `C:\Users\*`，深度清理所有账号的私有缓存。
*   **精准目标**：
    *   `AppData\Local\Temp`：各类软件运行产生的中间临时文件。
    *   `Pictures`：各类下载或生成的预览/缩略图。
    *   `Downloads`：清理各用户浏览器下载目录下的特定后缀垃圾（需配置）。
    *   `Documents\WXWorkLocal`：专门针对企业微信的缓存清理（仅清理 `Cache` 子目录，不伤及业务数据）。

### 2. 终极回收站清理 (V4.4 强力补丁)
*   **双模驱动**：优先尝试调用系统级 `SHEmptyRecycleBin` API，实现所有驱动器的快速静默清空。
*   **强力保底 (Nuke Mode)**：针对 API 失效（如 0x8000ffff 错误）或复杂权限环境，新增**文件级暴力扫描**。程序将直接锁定全盘 `$Recycle.Bin` 隐藏目录，无视后缀名，强制粉碎内部所有顽固残留。

### 3. 企业微信专项保护
*   **指纹识别**：依托深度路径分析，仅切除包含 `Cache` 关键字的内容。
*   **名单制防御**：支持严格的账号白名单，对于名单内的员工/领导账号，程序会自动跳过扫描，实现物理隔离，确保重要数据零风险。

### 4. 优化版自启动机制 (V4.3+)
*   **纯手动开启 (Default OFF)**：程序不再自动注册开机启动，将选择权完全交给用户。
*   **性能怪兽**：自启动任务被配置为 **CPU/IO 优先级 1 (最高)**，并取消了所有触发延迟（0 秒启动），确保用户登录桌面的一瞬间即可完成清理。
*   **免受 UAC 干扰**：利用 Windows 计划任务机制，实现一次管理员授权，永久静默后台运行。

## 快速上手

### 环境准备
*   操作系统：Windows 10/11 (x64)
*   Python 环境：Python 3.9+
*   主要依赖：`customtkinter`, `Rich`, `PyWin32`

### 部署与运行
1.  **直接运行 (源码)**：
    ```powershell
    python src/main.py
    ```
2.  **生成独立 EXE**：
    双击运行 `build.bat`。脚本会自动在 `dist/` 目录下生成单文件绿色版二进制程序，内置管理员权限请求清单。

---

## 进阶配置 (`config.json`)

```json
{
    "custom_paths": ["D:\\MyCustomCache"],
    "whitelist": ["Admin", "CEO_Account"]
}
```
*   **`whitelist`**：必须与文件夹名**完全匹配**（区分大小写）。匹配项在扫描阶段会被完全忽略。

---

## 目录结构
*   `src/`：核心业务逻辑（清理算法、GUI 动态绑定）。
*   `assets/`：UI 图标与多媒体资源。
*   `scripts/`：运维验证工具（如回收站 API 测试脚本）。
*   `build.bat`：单键打包自动化脚本。

## 安全警示
> [!IMPORTANT]
> **V4.4** 的回收站强制清理模式会永久删除文件。由于回收站的文件不再遵循后缀过滤规则，请确保您的回收站中没有误删的重要资料再执行清理。
